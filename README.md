# 2026 端午广州看龙舟 + 珠海三日地图攻略

这是一个纯静态 Web/H5 地图攻略项目，基于 `端午节攻略` 目录下的 Word 与 PPT 素材重构而来。

项目目标不是普通图文游记，而是把“去哪里、何时去、怎么过去、停留多久、花多少钱、风险是什么、如何导航”整理成可交互地图。

## 行程结论

核心口径：**6月19日上午在广州看龙舟，傍晚优先从广州东转珠海站；珠海住两晚，围绕吉大/城市阳台/情侣路减少折返；6月21日下午从珠海站返广州。**

不把珠海龙舟作为主线押注：原始攻略指出，珠海 2026 公开龙舟信息主要集中在节前活动，6月19日端午当天广州确定性更高。

## 三天路线

### Day 1｜广州龙舟观赛 + 傍晚进珠海

- 主看区域：二沙涌 / 寺右 / 杨箕
- 集合入口：五羊邨地铁站、寺右新马路、二沙岛星海音乐厅一带
- 午餐补充：广州酒家（体育东店）或体育东/天河北商圈
- 下午备选：猎德涌；如果太热、人多或车票紧张，直接休整
- 转场策略：16:00 前后撤向广州东站；无合适车次再改广州南
- 到站口径：买到珠海站，不优先珠海北
- 晚上安排：入住吉大/城市阳台，晚餐可选夏湾夜市、茶餐厅、生蚝

### Day 2｜珠海园林、北山与海岸线

- 上午：圆明新园
- 中午：北山大院 / 富华里二选一
- 下午：爱情邮局、珠海渔女、香炉湾、城市阳台
- 晚上：野狸岛 + 珠海大剧院（日月贝）

### Day 3｜景山/海滨公园 + 午餐后返广州

- 上午：景山公园 / 海滨公园
- 中午：香洲或吉大早茶/午餐，优先控制时间
- 下午：城市阳台、九洲城或香洲商圈轻松补逛
- 返程：建议锁定 16:30-17:30 珠海站返广州车次

## 本地预览

本项目不需要构建工具。

推荐用本地静态服务器预览，避免浏览器对定位、跨域或本地文件协议的限制：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可以直接打开 `index.html`，但手机定位、导航唤起和部分浏览器安全能力可能受限。

## 数据维护说明

主要维护文件：`js/data.js`

### 地点数据

每个地点建议包含：

- `id`：唯一标识
- `day`：归属日期
- `category`：地点类型
- `name`：名称
- `lng` / `lat`：WGS84 经纬度
- `short`：短描述
- `time`：推荐时段
- `cost`：人均、门票或交通预算
- `dwell`：建议停留时长
- `search`：地图 App 搜索关键词
- `transport`：公交/地铁/打车说明
- `walking`：步行建议
- `risk`：风险、排队、封控、天气或返程提醒
- `description`：详情介绍
- `tags`：标签
- `image`：图片路径

当前支持的类型：

- `dragon`：龙舟观赛
- `sight`：景点
- `food`：餐饮
- `station`：交通
- `stay`：住宿区域
- `backup`：备选

### 路线数据

每天的 `route` 字段引用地点 `id`，地图会按顺序绘制路线。

如果新增地点后需要进入路线，只要把地点 `id` 放入对应 Day 的 `route` 数组即可。

### 交通关键词

`transit` 用于维护“用户可复制到地图 App 的搜索词”。适合放：

- 集合点
- 地铁站
- 公交/打车锚点
- 住宿搜索范围
- 景点串联关键词
- 转场车站策略

## 导航能力说明

点击地点详情或地点列表中的“导航”按钮后：

- 手机端会尝试通过 Geolocation 获取当前位置
- 生成高德、百度、腾讯地图导航链接
- 优先唤起原生 App
- 如果 App 未安装或浏览器拦截，提供 Web 导航兜底
- 微信内置浏览器可能需要用户点击右上角在系统浏览器中打开

坐标统一按 WGS84 维护。不同地图 App 内部可能存在坐标系转换，实际导航以 App 实时结果为准。
